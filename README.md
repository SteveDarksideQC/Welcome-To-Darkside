## 🌌 About The Project

**Welcome to Darkside** is a premium post-install utility designed to transform a fresh Ubuntu 26.04+ installation into an absolute powerhouse. Built natively with Python and Libadwaita, it provides a beautiful, seamless GUI to apply aggressive hardware tweaks, auto-compile custom gaming kernels, and execute complex software installations without ever touching the terminal.

### 🔥 Key Features
* **Core System Tweaks:** 1-click latency reduction, max map count enforcement, BBR network optimization, and AMD P-State controls.
* **Kernel Command Center:** Install pre-compiled drop-in kernels (XanMod, Liquorix) or auto-compile a custom TKG kernel tailored to your CPU in minutes.
* **Deep Maintenance:** Instantly repair broken packages, safely clear caches, fix corrupted thumbnails, and rescue frozen GNOME/KDE desktop elements.
* **Macro Software Hub:** A massive catalog of 80+ dynamically detected apps. Includes specialized 1-click bundles like the **DaVinci Resolve Setup Engine** (which automatically extracts the installer, adds AMD ROCm, and applies the Ubuntu library fix so it actually launches natively).

## 🚀 Installation

Grab the latest `.deb` package from the [Releases](../../releases) page.

### Method 1: GUI (Recommended for Beginners)
1. Open your file manager and navigate to where you downloaded the `.deb` file.
2. Double-click the file to open it in your system's Software Center (or right-click and select "Open With Software Install").
3. Click **Install** and enter your password.
4. Search for **Darkside** in your application launcher!

### Method 2: Terminal (For Power Users)
Open your terminal and run the following commands:
``bash
# Navigate to your downloads folder
cd ~/Downloads

# Install the package and automatically resolve all dependencies
sudo apt install ./welcome-to-darkside_1.0.0_all.deb

🗑️ Uninstallation
If you need to remove the application from your system, simply run:
sudo apt remove welcome-to-darkside
(Note: This only removes the Darkside app itself. Any software, kernels, tweaks, or Flatpaks you installed using the app will remain safely on your system).

🐛 Bug Reports & Troubleshooting
If you encounter an issue, a crash, or a feature not working as intended, please open an Issue on this repository. To help track down the problem quickly, please include the following information in your report:

System Specs:

Operating System (e.g., Ubuntu 26.04)

Kernel Version (Run uname -r in terminal)

CPU & GPU models

Steps to Reproduce: Tell us exactly what you clicked or toggled before the app broke.

Terminal Output (Crucial!): To see what is breaking under the hood, run the app directly from your terminal so it catches the error logs. Paste the output into your bug report:
python3 /usr/share/welcome-to-darkside/main.py
Screenshots: If a UI element is broken or misaligned, include a screenshot!
